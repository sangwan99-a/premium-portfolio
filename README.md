# Sahil Sangwan — Portfolio

An immersive 3D portfolio for **Sahil Sangwan**, Full Stack Developer. The experience keeps the original cinematic 3D journey while personalizing the particle-name intro, content, metadata, and GitHub contact link.

## Tech stack

- React 18 + Vite
- Three.js with React Three Fiber and drei
- Custom GLSL shaders and post-processing
- Lenis smooth scrolling

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Personalize your details

- `src/content.js`: update the project cards, education/work timeline, stats, and certifications with verified information.
- `src/ui/Overlay.jsx`: edit the About paragraph and achievement copy.
- `src/ui/Contact.jsx`: update contact links and connect a real résumé file before enabling a résumé download.
- `src/world/Hero.jsx`: the particle-name intro currently morphs to **SAHIL**.
- `src/assets/lohitha.webp`: no longer used by the hero; add your own optimized portrait only if you later choose to build a portrait reveal.
